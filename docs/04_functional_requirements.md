# 04 Functional Requirements

Tabel berikut mencantumkan semua kebutuhan fungsional untuk aplikasi SALATIFY dengan kode unik:

| Kode | Nama Kebutuhan | Deskripsi | Aktor |
|------|----------------|-----------|-------|
| FR-01 | Registrasi Akun | Pengguna dapat mendaftar akun baru dengan memasukkan nama, email, dan password | Pengguna |
| FR-02 | Login | Pengguna dapat masuk ke aplikasi menggunakan email dan password yang terdaftar | Pengguna |
| FR-03 | Logout | Pengguna dapat keluar dari aplikasi | Pengguna |
| FR-04 | Mengelola Profil | Pengguna dapat mengubah informasi profil (nama, foto, preferensi) | Pengguna |
| FR-05 | Jadwal Sholat | Menampilkan jadwal sholat Subuh, Dzuhur, Ashar, Maghrib, dan Isya berdasarkan lokasi pengguna | Pengguna |
| FR-06 | Waktu Sholat Berikutnya | Menampilkan waktu tersisa hingga sholat berikutnya | Pengguna |
| FR-07 | Pengingat Sholat | Pengguna dapat mengaktifkan atau menonaktifkan pengingat shalat | Pengguna |
| FR-08 | Waktu Pengingat | Pengguna dapat mengatur waktu pengingat sebelum sholat mulai (misal: 5, 10, 15 menit) | Pengguna |
| FR-09 | GPS & Lokasi | Aplikasi dapat mendeteksi lokasi geografis pengguna menggunakan GPS | Pengguna |
| FR-10 | Arah Kiblat | Menampilkan arah kiblat berdasarkan koordinat GPS pengguna | Pengguna |
| FR-11 | Sensor Kompas | Menggunakan sensor kompas perangkat untuk menyejajikan arah kiblat | Pengguna |
| FR-12 | Koleksi Wirid | Menampilkan kumpulan wirid dan dzikir | Pengguna |
| FR-13 | Teks Arab Wirid | Menampilkan teks Arab dari wirid/dzikir | Pengguna |
| FR-14 | Teks Latin Wirid | Menampilkan teks Latin dari wirid/dzikir | Pengguna |
| FR-15 | Terjemahan Wirid | Menampilkan terjemahan bahasa Indonesia dari wirid/dzikir | Pengguna |
| FR-16 | Tasbih Digital | Menyediakan fitur tasbih digital untuk penghitungan pengulangan | Pengguna |
| FR-17 | Riwayat Dzikir | Menyimpan dan menampilkan riwayat pengulangan dzikir pengguna | Pengguna |
| FR-18 | Koleksi Doa | Menampilkan berbagai doa sehari-hari | Pengguna |
| FR-19 | Teks Arab Doa | Menampilkan teks Arab dari doa | Pengguna |
| FR-20 | Teks Latin Doa | Menampilkan teks Latin dari doa | Pengguna |
| FR-21 | Terjemahan Doa | Menampilkan terjemahan doa dalam bahasa Indonesia | Pengguna |
| FR-22 | Kategori Doa | Mengelompokkan doa berdasarkan kategori (contoh: pagi, malam, sebelum makan) | Pengguna |
| FR-23 | Pencarian Doa | Memungkinkan pengguna mencari doa berdasarkan kata kunci atau kategori | Pengguna |
| FR-24 | Doa Favorit | Pengguna dapat menandai doa sebagai favorit dan menyimpan di daftar tersendiri | Pengguna |
| FR-25 | Daftar Surah | Menampilkan daftar 114 surah Al-Qur'an | Pengguna |
| FR-26 | Info Surah | Menampilkan informasi tentang setiap surah (jumlah ayat, tempat turun, dll) | Pengguna |
| FR-27 | Pemutar Audio | Menyediakan pemutar audio untuk murottal Al-Qur'an | Pengguna |
| FR-28 | Fitur Play | Memulai pemutaran audio murottal | Pengguna |
| FR-29 | Fitur Pause | Menghentikan sementara pemutaran audio | Pengguna |
| FR-30 | Fitur Stop | Menghentikan pemutaran audio dan mengembalikan ke awal | Pengguna |
| FR-31 | Pengaturan Profil | Pengguna dapat mengubah pengaturan profil pengguna | Pengguna |
| FR-32 | Pengaturan Notifikasi | Pengguna dapat mengaktifkan/menonaktifkan notifikasi sistem | Pengguna |
| FR-33 | Preferensi Aplikasi | Pengguna dapat mengubah preferensi aplikasi (tema, bahasa, dll) | Pengguna |
| FR-34 | Penyimpanan Lokal | Semua data pengguna disimpan di database SQLite di perangkat | Pengguna |
| FR-35 | Data Sholat Offline | Jadwal sholat dapat diakses tanpa koneksi internet | Pengguna |

*Total 35 kebutuhan fungsional teridentifikasi untuk mencakup semua fitur utama SALATIFY.*
