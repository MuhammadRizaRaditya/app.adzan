# SALATIFY - Smart Islamic Companion

**Nama Aplikasi:** SALATIFY

**Slogan:** Your Daily Worship Companion  
**Versi:** 1.0 (Pengembangan Pertama)  
**Tahun:** 2026

## Deskripsi SALATIFY

SALATIFY adalah aplikasi mobile Android yang dirancang sebagai pendamping ibadah umat Islam. Aplikasi ini menyediakan berbagai fitur terkait ibadah harian melalui satu platform terintegrasi, termasuk:

- Jadwal sholat berdasarkan lokasi pengguna
- Pengingat shalat dengan waktu yang dapat disesuaikan
- Arah kiblat menggunakan GPS dan sensor kompas
- Koleksi wirid dan dzikir dengan teks Arab, Latin, dan terjemahan
- Doa sehari-hari dengan kategori dan fitur pencarian
- 114 surah Al-Qur'an dengan pemutar audio murottal
- Pengelolaan profil dan preferensi pengguna

Aplikasi dibangun menggunakan teknologi cross-platform Python dengan Kivy dan KivyMD, serta database SQLite untuk penyimpanan data lokal.

## Tujuan Aplikasi

1. Memudahkan pengguna menjalankan ibadah shalat tepat waktu berdasarkan lokasi
2. Menjadi referensi lengkap untuk wirid, dzikir, dan doa sehari-hari
3. Memudahkan akses ke 114 surah Al-Qur'an dengan pemutaran audio
4. Membantu pengguna menjalani rutinitas ibadah harian yang lebih teratur
5. Menyediakan satu aplikasi pengganti berbagai referensi ibadah terpisah

## Fitur Utama

1. **Login & Register** - Pendaftaran akun dan manajemen profil
2. **Jadwal Sholat** - Jadwal berdasarkan lokasi dengan waktu remaining
3. **Pengingat Shalat** - Aktifkan/nonaktifkan dan setting waktu sebelum sholat
4. **Arah Kiblat** - Menggunakan GPS dan sensor kompas perangkat
5. **Wirid & Dzikir** - Teks Arab, Latin, terjemahan, dan tasbih digital
6. **Kumpulan Doa** - Berbagai doa dengan kategori dan fitur pencarian
7. **Murottal Al-Qur'an** - 114 surah dengan pemutar play/pause/stop
8. **Pengaturan** - Tema, bahasa, notifikasi, dan preferensi aplikasi

## Teknologi yang Direncanakan

- **Bahasa Pemrograman:** Python 3.9+
- **Framework UI:** Kivy dan KivyMD (cross-platform)
- **Database:** SQLite (local storage)
- **Build Tool:** Buildozer (kompilasi ke APK Android)
- **Android API Access:** Pyjnius
- **Hardware Access:** Plyer (GPS, kompas, notifikasi)
- **HTTP Client:** Requests (untuk konten tambahan)
